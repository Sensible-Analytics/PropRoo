# PropRoo Backend

FastAPI backend serving NSW property sales analytics via DuckDB + Parquet files. Zero external dependencies — no PostgreSQL, Redis, or S3.

## Architecture

- **ETL Pipeline** (`etl/`): Downloads NSW Valuer General data → parses → writes Parquet files
- **API** (`app/`): FastAPI + DuckDB queries on local Parquet files
- **Data** (`data/`): Parquet files generated by ETL (not committed to git)

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run ETL pipeline (generates Parquet files in data/)
python -m etl.ingest
python -m etl.geocode --data-dir data
python -m etl.calculate_growth

# Start API server
uvicorn app.main:app --reload
```

## ETL Pipeline

### 1. Ingest (`etl/ingest.py`)
Downloads NSW property sales ZIPs, parses DAT files, writes `sales.parquet`.
```bash
python -m etl.ingest --start-year 2024 --end-year 2024
```

### 2. Geocode (`etl/geocode.py`)
Matches properties to Australian postcodes, fills lat/lng in `sales.parquet`.
```bash
python -m etl.geocode --data-dir data
```

### 3. Calculate Growth (`etl/calculate_growth.py`)
Computes CAGR per property, generates summary Parquet files.
```bash
python -m etl.calculate_growth
```

## Parquet Files

| File | Rows | Description |
|------|------|-------------|
| `sales.parquet` | ~1M | Raw property sales with lat/lng |
| `property_growth.parquet` | ~100K | Per-property CAGR metrics |
| `street_summary.parquet` | ~100K | Per-street aggregated stats |
| `suburb_summary.parquet` | ~4K | Per-suburb aggregated stats |

## API Endpoints

- **Sales**: `/api/sales/*` — Property search, trends, top performers
- **Stats**: `/api/stats/*` — Global summaries, suburb centroids
- **Map**: `/api/map/*` — H3 clustering, viewport queries

Swagger UI: `http://localhost:8000/docs`

## Deployment

### Render
Deploy via `render.yaml` — single web service with `/data` volume mount.

### Docker
```bash
docker build -t proproo-backend .
docker run -p 8000:8000 -v parquet_data:/data proproo-backend
```

## Configuration

| Env Var | Default | Description |
|---------|---------|-------------|
| `DATA_DIR` | `data/` | Path to Parquet files |
| `ENVIRONMENT` | `development` | `development` or `production` |
